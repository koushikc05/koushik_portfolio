# Koushik C. | Personal Portfolio

A professional, high-fidelity personal portfolio website designed to showcase my projects, skills, and academic background as a 2nd-Year B.Tech Computer Science student specializing in AI/ML, Generative AI, and Full-Stack Development.

## 🚀 Overview

This portfolio serves as a central hub for my technical work, featuring a modern, dark-mode, glassmorphic design system. It highlights my focus on building intelligent applications using Agentic AI systems and designing scalable backend infrastructures.

## 💻 Tech Stack

- **Markup & Styling:** HTML5, CSS3, Tailwind CSS (via CDN with Custom Configuration)
- **Scripting:** Vanilla JavaScript
- **Typography & Icons:** Google Fonts (Inter, Geist), Google Material Symbols
- **Design System:** Custom Dark Mode Theme with Glassmorphism and CSS Custom Properties

## 🌟 Key Features

- **Modern & Responsive UI:** A premium, "touch-first" design layout optimized for both mobile devices and large desktop displays.
- **Glassmorphic Aesthetics:** Incorporates semi-transparent backgrounds, blurs, and gradient lighting for a futuristic, deep-tech feel.
- **Multi-Page Architecture:**
  - **Home (`index.html`):** Hero section, quick biography, and featured project highlights.
  - **About (`about.html`):** In-depth background on my journey and interests.
  - **Projects (`projects.html`):** A bento-grid layout detailing technical architectures and selected works.
  - **Skills & Education (`skills.html`):** Categorized technical skills (Frontend, Backend, AI/ML) and academic timeline.

## ⚙️ Setup & Installation

Since this project uses vanilla web technologies and a CDN-delivered Tailwind configuration, it requires no complex build step to run locally.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/koushikc05/koushik_portfolio.git
   cd portfolio
   ```

2. **Run the project:**
   You can serve the project using any standard local web server.
   * **Using VS Code:** Install the "Live Server" extension, right-click `pages/index.html`, and select "Open with Live Server".
   * **Using Python:**
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000/pages/index.html` in your browser.
