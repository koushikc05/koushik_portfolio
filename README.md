# Koushik C. | Personal Portfolio

A professional, single-page portfolio website showcasing my projects, skills, and academic background as a 3rd-Year B.Tech Computer Science student specializing in AI/ML, Generative AI, and Full-Stack Development.

## 🚀 Overview

A clean, single-page scrolling site with a black-and-white design theme and lightweight 3D visual elements powered by Three.js. It highlights my focus on building intelligent applications using Agentic AI systems and designing scalable backend infrastructures.

## 💻 Tech Stack

- **Markup & Styling:** HTML5, Vanilla CSS
- **Scripting:** Vanilla JavaScript
- **3D Graphics:** Three.js (via CDN)
- **Typography & Icons:** Google Fonts (Inter, Geist), Google Material Symbols

## 🌟 Key Features

- **Single-Page Architecture:** Sticky navbar with smooth anchor-link navigation — Hero → About → Projects → Skills & Education → Contact
- **Black & White Design:** Clean minimal aesthetic with off-white backgrounds, black text, and monochrome accents
- **Curated Dual-Row Tech Stack:** 7 Core Stack tools + 3 Currently Exploring tools
- **3D Visual Elements (Three.js):**
  - Animated wireframe particles + floating icosahedron in the hero section
  - Interactive 3D carousel cylinder with drag-to-spin and cursor parallax in the Skills section
  - 3D perspective tilt on project cards
- **Scroll-Spy Navigation:** Active nav link updates as you scroll
- **Scroll-Reveal Animations:** Elements fade in on viewport entry
- **Mobile Responsive:** Hamburger drawer, stacked layouts, full-width buttons

## ⚙️ Setup

No build step required — just open the HTML file.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/koushikc05/koushik_portfolio.git
   cd koushik_portfolio
   ```

2. **Run locally:**
   - **VS Code:** Install "Live Server", right-click `index.html` → "Open with Live Server"
   - **Python:** `python -m http.server 8000` → open `http://localhost:8000`
